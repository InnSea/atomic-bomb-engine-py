# atomic-bomb-engine-py 本地开发指南

本文档介绍如何在修改代码后本地编译和使用 atomic-bomb-engine-py。

## 前置条件

### 1. 安装 Rust 工具链

访问 [https://rustup.rs/](https://rustup.rs/) 安装 Rust，或使用以下命令：

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

安装完成后，重新加载环境变量：

```bash
source $HOME/.cargo/env
```

验证安装：

```bash
rustc --version
cargo --version
```

### 2. 安装 Maturin

Maturin 是用于构建和发布 Rust Python 包的工具。

```bash
pip install maturin
```

或者使用 pipx 安装（推荐）：

```bash
pipx install maturin
```

### 3. 安装 Python（版本 >= 3.8）

确保你的系统已安装 Python 3.8 及以上版本：

```bash
python3 --version
```

## 开发流程

### 方式一：开发模式安装（推荐）

这是最方便的开发方式，修改代码后可以快速测试。

1. **进入项目目录**：

```bash
cd /Users/tanlinhai/atomic-bomb-engine-py
```

2. **使用开发模式安装**：

```bash
maturin develop
```

这个命令会：
- 编译 Rust 代码
- 将编译后的扩展模块安装到当前 Python 环境
- 支持快速迭代开发

3. **如果需要 release 模式（性能更好）**：

```bash
maturin develop --release
```

4. **测试你的修改**：

```python
import atomic_bomb_engine

# 创建 runner
runner = atomic_bomb_engine.BatchRunner()

# 使用新增的 stop 方法
# runner.stop()  # 可以在需要时调用此方法停止压测
```

### 方式二：构建 wheel 包

如果你想构建可分发的 wheel 包：

1. **构建 wheel 包**：

```bash
maturin build --release
```

编译后的 wheel 包会在 `target/wheels/` 目录下。

2. **安装构建的 wheel 包**：

```bash
pip install target/wheels/atomic_bomb_engine-0.41.3-cp311-cp311-macosx_11_0_arm64.whl
```

注意：文件名会根据你的 Python 版本和系统架构而变化。

### 方式三：直接从源码安装

```bash
pip install .
```

这会自动调用 maturin 构建并安装。

## 使用示例：如何使用新增的 stop 方法

### 示例 1：基本使用

```python
import asyncio
import atomic_bomb_engine

async def main():
    runner = atomic_bomb_engine.BatchRunner()
    
    # 启动压测
    runner.run(
        test_duration_secs=60,  # 设置 60 秒，但我们会提前停止
        concurrent_requests=100,
        api_endpoints=[
            atomic_bomb_engine.endpoint(
                name="test-api",
                url="http://127.0.0.1:8080/api",
                method="POST",
                json={"test": "data"},
                weight=100,
            ),
        ]
    )
    
    # 开始监听结果
    count = 0
    for res in runner:
        if res.get("should_wait"):
            await asyncio.sleep(0.1)
        else:
            print(res)
            count += 1
            
            # 在收到 5 个结果后停止压测
            if count >= 5:
                print("达到 5 个结果，停止压测...")
                runner.stop()
                break

if __name__ == '__main__':
    asyncio.run(main())
```

### 示例 2：在异步任务中使用

```python
import asyncio
import atomic_bomb_engine

async def run_test():
    runner = atomic_bomb_engine.BatchRunner()
    
    runner.run(
        test_duration_secs=120,
        concurrent_requests=200,
        api_endpoints=[
            atomic_bomb_engine.endpoint(
                name="test-1",
                url="http://127.0.0.1:8080/direct",
                method="POST",
                json={"name": "test-1", "number": 1},
                weight=100,
            ),
        ]
    )
    
    return runner

async def monitor_and_stop(runner, max_errors=10):
    """监控压测并在错误数超过阈值时停止"""
    total_errors = 0
    
    for res in runner:
        if res.get("should_wait"):
            await asyncio.sleep(0.1)
        else:
            print(res)
            
            # 统计错误数
            if 'err_count' in res:
                total_errors = res['err_count']
                
                # 如果错误数超过阈值，停止压测
                if total_errors >= max_errors:
                    print(f"错误数达到 {total_errors}，停止压测！")
                    runner.stop()
                    break

async def main():
    runner = await run_test()
    await monitor_and_stop(runner, max_errors=10)

if __name__ == '__main__':
    asyncio.run(main())
```

### 示例 3：使用信号处理优雅停止

```python
import asyncio
import signal
import atomic_bomb_engine

runner = None

def signal_handler(signum, frame):
    """处理 Ctrl+C 信号"""
    if runner:
        print("\n接收到停止信号，正在停止压测...")
        runner.stop()

async def main():
    global runner
    
    # 注册信号处理器
    signal.signal(signal.SIGINT, signal_handler)
    
    runner = atomic_bomb_engine.BatchRunner()
    
    runner.run(
        test_duration_secs=300,
        concurrent_requests=100,
        api_endpoints=[
            atomic_bomb_engine.endpoint(
                name="test-api",
                url="http://127.0.0.1:8080/api",
                method="GET",
                weight=100,
            ),
        ]
    )
    
    print("压测已启动，按 Ctrl+C 停止...")
    
    for res in runner:
        if res.get("should_wait"):
            await asyncio.sleep(0.1)
        else:
            print(res)

if __name__ == '__main__':
    asyncio.run(main())
```

## 常见问题

### 1. 编译失败

**问题**：运行 `maturin develop` 时出现编译错误。

**解决方案**：
- 确保 Rust 工具链是最新的：`rustup update`
- 清理并重新编译：`cargo clean && maturin develop`

### 2. 找不到模块

**问题**：Python 中导入时报错 `ModuleNotFoundError: No module named 'atomic_bomb_engine'`

**解决方案**：
- 确保在正确的 Python 环境中运行 `maturin develop`
- 如果使用虚拟环境，确保已激活：`source venv/bin/activate`

### 3. 性能问题

**问题**：开发模式下性能较差。

**解决方案**：
- 使用 release 模式编译：`maturin develop --release`
- release 模式会启用优化，性能会大幅提升

### 4. 修改后不生效

**问题**：修改代码后，Python 中的行为没有变化。

**解决方案**：
- 重新运行 `maturin develop` 重新编译
- 重启 Python 解释器或 Jupyter kernel

## Docker 部署方案（推荐）

### 问题说明

在Docker容器中安装Rust工具链会显著增加镜像大小（约1-2GB），且构建时间长。**推荐方案是在本地构建Linux版本的wheel包，然后直接在Docker中安装**。

### 步骤 1：在本地构建 Linux 版本的 wheel 包

#### 方法一：使用 Docker 交叉编译（推荐，最简单）

创建一个临时的构建容器来编译Linux版本：

```bash
# 在项目根目录执行
docker run --rm -v $(pwd):/io \
  ghcr.io/pyo3/maturin build --release -i python3.12 -i python3.11 -i python3.10 -i python3.9 -i python3.8
```

编译后的wheel包会在 `target/wheels/` 目录下，文件名类似：
```
atomic_bomb_engine-0.41.4-cp312-cp312-manylinux_2_34_x86_64.whl
```

#### 方法二：使用本地 Rust 交叉编译

如果你想在本地Mac上直接编译Linux版本（需要额外配置）：

```bash
# 添加Linux目标
rustup target add x86_64-unknown-linux-gnu

# 安装交叉编译工具链（Mac上需要）
brew install filosottile/musl-cross/musl-cross

# 构建Linux版本
maturin build --release --target x86_64-unknown-linux-gnu -i python3.12
```

### 步骤 2：修改 Dockerfile

在你的项目中创建一个 `wheels` 目录，将编译好的wheel包放进去：

```bash
# 在你的项目根目录
mkdir -p wheels
cp /path/to/atomic-bomb-engine-py/target/wheels/*.whl ./wheels/
```

然后修改 Dockerfile：

```dockerfile
FROM selenium/standalone-chrome:latest AS chrome-source

FROM python:3.12.12-slim

# 环境变量设置
ENV TZ=Asia/Shanghai
ENV CRYPTOGRAPHY_DONT_BUILD_RUST=1
ENV PYTHONUNBUFFERED=1
ENV JAVA_HOME=/opt/java
ENV JMETER_HOME=/usr/share/jmeter
ENV JMETER_VERSION=5.6.3
ENV NODE_HOME=/opt/node
ENV NODE_VERSION=20.19.4
ENV PATH=$NODE_HOME/bin:$JAVA_HOME/bin:$JMETER_HOME/bin:$PATH
ENV CHROME_BIN=/usr/bin/google-chrome-stable
ENV CHROME_PATH=/usr/lib/chrome
ENV DISPLAY=:99

USER root

# ... 你的其他设置保持不变 ...

WORKDIR /tester

# 先复制并安装自定义的 wheel 包
COPY wheels/*.whl /tmp/wheels/
RUN python3 -m pip install --no-cache-dir /tmp/wheels/*.whl && \
    rm -rf /tmp/wheels

# 安装其他 Python 依赖
COPY requirements.txt .
RUN python3 -m pip install --no-cache-dir -i http://mirrors.aliyun.com/pypi/simple/ --trusted-host mirrors.aliyun.com -r requirements.txt

COPY . .

# ... 你的清理工作保持不变 ...

CMD ["gunicorn", "-c", "./gunicorn.py", "server:app"]
```

**注意**：从 requirements.txt 中移除 `atomic-bomb-engine`（如果有的话），因为我们已经手动安装了自定义版本。

### 步骤 3：更新 requirements.txt

如果你的 requirements.txt 中有 `atomic-bomb-engine`，将其注释掉或删除：

```txt
# atomic-bomb-engine==0.41.3  # 使用本地编译的版本
aiohttp
aiosqlite
# ... 其他依赖
```

### 步骤 4：构建和测试

```bash
# 构建 Docker 镜像
docker build -t your-image-name .

# 测试是否安装成功
docker run --rm your-image-name python3 -c "import atomic_bomb_engine; print(atomic_bomb_engine.__file__)"

# 测试 stop 方法是否可用
docker run --rm your-image-name python3 -c "
import atomic_bomb_engine
runner = atomic_bomb_engine.BatchRunner()
print('stop method exists:', hasattr(runner, 'stop'))
"
```

### 完整的自动化脚本

创建一个 `build-and-deploy.sh` 脚本来自动化整个流程：

```bash
#!/bin/bash
set -e

echo "开始构建流程..."

# 1. 构建 Linux 版本的 wheel 包
echo "1. 构建 atomic-bomb-engine-py wheel 包..."
cd /Users/tanlinhai/atomic-bomb-engine-py
docker run --rm -v $(pwd):/io \
  ghcr.io/pyo3/maturin build --release -i python3.12

# 2. 复制 wheel 包到你的项目
echo "2. 复制 wheel 包到项目..."
YOUR_PROJECT_PATH="/path/to/your/project"  # 修改为你的项目路径
mkdir -p $YOUR_PROJECT_PATH/wheels
cp target/wheels/*.whl $YOUR_PROJECT_PATH/wheels/

# 3. 构建 Docker 镜像
echo "3. 构建 Docker 镜像..."
cd $YOUR_PROJECT_PATH
docker build -t your-image-name .

echo "✓ 构建完成！"
echo "现在可以使用: docker run your-image-name"
```

### 方案优势

✅ **镜像体积小**：不需要在容器中安装Rust工具链（节省约1-2GB）  
✅ **构建速度快**：Docker构建时只需安装预编译的wheel包（秒级完成）  
✅ **易于维护**：修改代码后只需重新编译wheel包  
✅ **版本控制**：wheel包可以版本化管理  

### 替代方案：多阶段构建（不推荐）

如果你坚持要在Docker中编译（不推荐，会很慢且镜像大）：

```dockerfile
# 第一阶段：构建
FROM rust:1.75 as builder
RUN pip install maturin
COPY atomic-bomb-engine-py /build
WORKDIR /build
RUN maturin build --release

# 第二阶段：运行
FROM python:3.12.12-slim
COPY --from=builder /build/target/wheels/*.whl /tmp/
RUN pip install /tmp/*.whl
# ... 其他步骤
```

但这会让每次构建都非常慢（需要编译Rust代码）。
