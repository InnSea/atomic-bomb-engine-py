# 快速开始：添加 stop 功能并部署到 Docker

## 📋 概述

本项目已添加 `stop()` 方法，可以立即停止正在运行的压测。本文档介绍如何在 Docker 环境中使用修改后的版本。

## 🚀 三步部署

### 1️⃣ 构建 Linux wheel 包

```bash
cd /Users/tanlinhai/atomic-bomb-engine-py
./build_for_docker.sh
```

完成后，wheel 包在 `target/wheels/` 目录。

### 2️⃣ 复制到你的项目

```bash
# 替换为你的项目路径
YOUR_PROJECT="/path/to/your/project"

mkdir -p $YOUR_PROJECT/wheels
cp target/wheels/*.whl $YOUR_PROJECT/wheels/
```

### 3️⃣ 修改 Dockerfile

在 `WORKDIR /tester` 之后，`pip install requirements.txt` **之前**添加：

```dockerfile
# 安装自定义的 atomic-bomb-engine
COPY wheels/*.whl /tmp/wheels/
RUN python3 -m pip install --no-cache-dir /tmp/wheels/*.whl && \
    rm -rf /tmp/wheels
```

## ✅ 验证

```bash
docker build -t your-image .
docker run --rm your-image python3 -c "
import atomic_bomb_engine
runner = atomic_bomb_engine.BatchRunner()
print('stop 方法可用:', hasattr(runner, 'stop'))
"
```

## 💡 使用 stop 方法

```python
import asyncio
import atomic_bomb_engine

async def main():
    runner = atomic_bomb_engine.BatchRunner()
    
    runner.run(
        test_duration_secs=60,
        concurrent_requests=100,
        api_endpoints=[
            atomic_bomb_engine.endpoint(
                name="test",
                url="http://example.com/api",
                method="GET",
                weight=100,
            ),
        ]
    )
    
    count = 0
    for res in runner:
        if res.get("should_wait"):
            await asyncio.sleep(0.1)
        else:
            print(res)
            count += 1
            
            # 收到 5 个结果后停止
            if count >= 5:
                runner.stop()  # 👈 新增的停止方法
                break

asyncio.run(main())
```

## ⚠️ 注意事项

1. **requirements.txt**：如果有 `atomic-bomb-engine`，请注释掉：
   ```txt
   # atomic-bomb-engine  # 使用本地编译版本
   ```

2. **Dockerfile 顺序**：必须先安装 wheel 包，再安装 requirements.txt

3. **版本匹配**：确保使用的是 Python 3.8+ 的 wheel 包

## 🎯 常见使用场景

### 场景 1：错误率过高时停止

```python
for res in runner:
    if not res.get("should_wait"):
        if res.get('error_rate', 0) > 10:  # 错误率超过 10%
            print("错误率过高，停止压测")
            runner.stop()
            break
```

### 场景 2：达到目标请求数后停止

```python
for res in runner:
    if not res.get("should_wait"):
        if res.get('total_requests', 0) >= 1000:
            print("已完成 1000 个请求，停止")
            runner.stop()
            break
```

### 场景 3：API 端点停止压测

```python
from fastapi import FastAPI

app = FastAPI()
tester = LoadTester()

@app.post("/start-test")
async def start_test(config: dict):
    await tester.start_test(config)
    return {"status": "started"}

@app.post("/stop-test")
async def stop_test():
    tester.stop_test()  # 调用 runner.stop()
    return {"status": "stopped"}
```
