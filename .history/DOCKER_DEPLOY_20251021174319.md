# Docker 部署快速指南

本文档介绍如何将修改后的 atomic-bomb-engine-py 部署到 Docker 容器中，**无需在容器中安装 Rust**。

## 核心思路

```
┌─────────────┐      ┌──────────────┐      ┌─────────────┐
│ 修改 Rust   │ ───> │ 本地构建为   │ ───> │ Docker 中   │
│ 源代码      │      │ Linux wheel  │      │ 直接安装    │
└─────────────┘      └──────────────┘      └─────────────┘
```

## 快速开始（3步完成）

### 第 1 步：构建 Linux 版本的 wheel 包

在 `atomic-bomb-engine-py` 目录下执行：

```bash
cd /Users/tanlinhai/atomic-bomb-engine-py

# 运行构建脚本（推荐）
./build_for_docker.sh
```

或者手动执行：

```bash
docker run --rm -v $(pwd):/io \
  ghcr.io/pyo3/maturin build --release -i python3.12
```

构建完成后，wheel 包会在 `target/wheels/` 目录下。

### 第 2 步：将 wheel 包复制到你的项目

```bash
# 在你的项目根目录
YOUR_PROJECT="/path/to/your/project"  # 修改为实际路径

# 创建 wheels 目录
mkdir -p $YOUR_PROJECT/wheels

# 复制 wheel 包
cp target/wheels/atomic_bomb_engine-0.41.4-*.whl $YOUR_PROJECT/wheels/
```

### 第 3 步：修改 Dockerfile

在你的 Dockerfile 中，**在安装 requirements.txt 之前**添加：

```dockerfile
WORKDIR /tester

# 【新增】先安装自定义的 atomic-bomb-engine
COPY wheels/*.whl /tmp/wheels/
RUN python3 -m pip install --no-cache-dir /tmp/wheels/*.whl && \
    rm -rf /tmp/wheels

# 然后安装其他依赖
COPY requirements.txt .
RUN python3 -m pip install --no-cache-dir \
    -i http://mirrors.aliyun.com/pypi/simple/ \
    --trusted-host mirrors.aliyun.com \
    -r requirements.txt

COPY . .
# ... 后续步骤
```

### 第 4 步：构建和测试

```bash
# 构建镜像
docker build -t your-image-name .

# 验证安装
docker run --rm your-image-name python3 -c "
import atomic_bomb_engine
runner = atomic_bomb_engine.BatchRunner()
print('✓ atomic-bomb-engine 已安装')
print('✓ stop 方法可用:', hasattr(runner, 'stop'))
runner.stop()
print('✓ 测试通过！')
"
```

## 自动化脚本

创建一个 `update_and_build.sh` 脚本来自动化整个流程：

```bash
#!/bin/bash
set -e

# 配置
ENGINE_PATH="/Users/tanlinhai/atomic-bomb-engine-py"
PROJECT_PATH="/path/to/your/project"  # 修改为你的项目路径
IMAGE_NAME="your-image-name"          # 修改为你的镜像名

echo "1. 构建 atomic-bomb-engine wheel 包..."
cd $ENGINE_PATH
./build_for_docker.sh

echo "2. 复制 wheel 包到项目..."
mkdir -p $PROJECT_PATH/wheels
rm -f $PROJECT_PATH/wheels/*.whl  # 清理旧版本
cp target/wheels/*.whl $PROJECT_PATH/wheels/

echo "3. 构建 Docker 镜像..."
cd $PROJECT_PATH
docker build -t $IMAGE_NAME .

echo "4. 测试镜像..."
docker run --rm $IMAGE_NAME python3 -c "
import atomic_bomb_engine
runner = atomic_bomb_engine.BatchRunner()
assert hasattr(runner, 'stop'), 'stop 方法不存在'
print('✓ 所有测试通过')
"

echo "✓ 完成！镜像已准备就绪: $IMAGE_NAME"
```

## 使用新增的 stop 方法

在你的服务代码中：

```python
import asyncio
import atomic_bomb_engine

class LoadTester:
    def __init__(self):
        self.runner = None
    
    async def start_test(self, config):
        """启动压测"""
        self.runner = atomic_bomb_engine.BatchRunner()
        
        self.runner.run(
            test_duration_secs=config.get('duration', 60),
            concurrent_requests=config.get('concurrent', 100),
            api_endpoints=[
                atomic_bomb_engine.endpoint(
                    name="api-test",
                    url=config['url'],
                    method=config.get('method', 'GET'),
                    weight=100,
                ),
            ]
        )
        
        # 监听结果
        for res in self.runner:
            if res.get("should_wait"):
                await asyncio.sleep(0.1)
            else:
                # 发送结果到前端或处理
                yield res
    
    def stop_test(self):
        """停止压测（新增功能）"""
        if self.runner:
            self.runner.stop()
            print("压测已停止")
```

## 常见问题

### Q1: 为什么不直接在 Docker 中编译？

**A:** 在 Docker 中编译需要：
- 安装 Rust 工具链（约 1.5GB）
- 每次构建都要编译（5-10 分钟）
- 最终镜像会非常大

使用预编译的 wheel 包：
- 镜像大小不变
- 构建速度快（秒级）
- 更容易维护和版本控制

### Q2: 如果修改了代码怎么办？

**A:** 重新构建 wheel 包并替换：

```bash
cd /Users/tanlinhai/atomic-bomb-engine-py
./build_for_docker.sh
cp target/wheels/*.whl /path/to/your/project/wheels/
cd /path/to/your/project
docker build -t your-image .
```

### Q3: wheel 包可以提交到 Git 吗？

**A:** 可以，但有两种方案：

**方案 1**（推荐）：不提交 wheel 包，在 CI/CD 中构建

```bash
# .gitignore
wheels/

# 在 CI/CD 中
./build_for_docker.sh
cp target/wheels/*.whl wheels/
docker build -t $IMAGE .
```

**方案 2**：提交 wheel 包（适合简单场景）

```bash
git add wheels/*.whl
git commit -m "Update atomic-bomb-engine wheel"
```

### Q4: 如何支持多个 Python 版本？

构建时指定多个版本：

```bash
docker run --rm -v $(pwd):/io \
  ghcr.io/pyo3/maturin build --release \
  -i python3.8 \
  -i python3.9 \
  -i python3.10 \
  -i python3.11 \
  -i python3.12
```

然后选择对应版本的 wheel 包复制到项目中。
